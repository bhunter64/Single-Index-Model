\section{Appendix}

\subsection{Supporting information}
\label{appendixA}

This appendix provides detailed results for the fixed-threshold single-index
model described in the main text. Because the revised model fixes the index
intercept at one and the threshold at zero, no separate cut-point, angular
parameter, or angular-range sensitivity analysis is reported. Likewise, the
earlier five-biomarker angular simulations and univariate biomarker-screening
analysis were not repeated under the present formulation.
